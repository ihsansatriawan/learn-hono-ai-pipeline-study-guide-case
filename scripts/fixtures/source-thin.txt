Short note: let and const

There are two things to hold on to about modern variable declarations in JavaScript.

First, const means the binding cannot be moved. Once a name is bound to a value with
const, that name may not be pointed at a different value. The common misunderstanding:
this does not mean the value is frozen. An object bound with const may still have its
contents changed; the only thing forbidden is reassigning the name to a different
object.

Second, let and const are bound to the block, not to the function. A variable declared
inside a pair of curly braces lives only inside those braces. This differs from var,
which leaks out to the whole function it was declared in, and that is the source of many
mistakes in loops that create closures.
